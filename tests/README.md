# Test inventory

This list is the whole test suite. Each entry locks the contract it names.
Follow the [test rules](../AGENTS.md#testing): refactors never
change tests, and adding or removing an entry is a recorded decision.

An entry is "built" when the test exists and passes.

**Running them.** The contract suites are one executable, `frizzle_tests`,
which `python3 scripts/check.py test` (and `all`) builds and runs, with the
app's TypeScript suites and type check, so it needs `npm ci` in `app/`.
The oracle is `frizzle_oracle`, run by hand when the inference path changes:

```sh
cmake --build build/native-debug --target frizzle_oracle
build/native-debug/tests/frizzle_oracle
```

The contract suites read only committed inputs. The oracle reads the pinned
model file (`python3 scripts/fetch_model.py`); a missing file fails it, never
skips it.

## Integration scenarios (three of five)

| Scenario | Contract it guards | Status |
| --- | --- | --- |
| Logits vs llama.cpp | The native engine, on Dawn, computes Gemma 3 1B's logits for fixed token sequences within a frozen tolerance of llama.cpp's for the same file. Run when the inference path changes, not with the routine suite. `tests/integration/reference-logits/`, against the frozen reference in `tests/fixtures/reference/`. | Built |
| Replay and edits | Through the engine, on the pinned model, one message and one seed. (1) Scale × 1 edits in several layers give the reply without edits, byte for byte, with the same token count and ending. (2) Without edits, then with a strong edit from step 0, then without again: the third run equals the first, and reuses all the prompt's cache but its last token, the first position whose edits differ. (3) One edit set across layers, given in two orders, gives one reply, different from the reply without edits. (4) After an edited run, a conversation that contains its reply reuses only the prompt before the edits, and its reply equals a fresh engine's. (5) A branch keeping the original's first k tokens, with no edits, continues it bit for bit, k at the start, inside and at the end, given what the original's limit leaves after k (a run's limit counts what it emits). (6) A steered branch accepted, the cache cut below it, then a branch further on with its history continues the accepted reply bit for bit, recomputing its edited positions; so does a fresh engine. (7) An inspection at k emits nothing, ends Limit, and captures what the branch from k captures, every word of the store, bit for bit, at the same position. (8) A kept identifier past the vocabulary is refused, Kept, by index. `tests/integration/replay/`, `frizzle_replay`, run when edits, the graph or the turn loop change. | Built |
| Site build | The Hugo site builds and publishes with the app inside it. | Planned |

Two slots are unassigned. Browser, end to end (the app as it ships, in
a real browser with WebGPU, driven by puppeteer-core) was dropped on
2026-11-02: four of about thirty runs hung for five minutes before the
model loaded, and the cause was not found. The page, worker and module
have no end-to-end test until the tests are audited (QUEUE).

## Contract suites

| Suite | Contract it guards | Status |

| Tokenizer | Prompts tokenize to the reference token IDs for Gemma 3's vocabulary, and token IDs decode back to the same text. `tests/contracts/tokenizer/`, over the model's vocabulary alone in `tests/fixtures/tokenizer/` (`scripts/make_tokenizer_fixture.py`). | Built |
| Model file | A malformed or hostile GGUF is refused by name, never read past its bounds or misinterpreted. `tests/contracts/gguf/`, over the files `scripts/make_gguf_fixtures.py` writes. | Built |
| Kernels | A kernel alone on the GPU, with no model, against a CPU reference. The edit kernel, against `edit::apply` bit for bit: each listed neuron becomes `apply`'s result in exactly the rows whose positions its range holds, in any step, prefill or decode, scoring or not; a range beginning or ending inside a block edits its side only; two ranges of one neuron each edit their own rows; a decode step past a range changes nothing; a layer's launch applies its own layer's edits and no other's; more than 64 edits in a layer all apply; Scale × 1 keeps a subnormal's bits; every other value keeps its bits. `tests/contracts/kernels/`, `frizzle_kernels`, in the routine run; it needs a GPU and fails without one. The capture, with its reader, against the activation it copies, bit for bit: the activation's last row lands in its layer's slot of the store in the step that ends the prompt (a prefill block, or the one-token recompute of the last prompt position) and in no other, never outside its slot; the store reads back as its bits; every layer's neurons come first, each after the earlier layers', then each layer's residual, two additions, weights and stats, the weights min(window, trained context) keys a head. The norm's capture: in the step that ends the prompt, from its last row only, the residual slot holds X as the launch leaves it (as read, where it does not add) and the added slot y as added, so X before plus y, one f32 add, is X written, bit for bit; the final norm's from its last row too; X and normed the same bits whether the step captures or not; nothing written in a decode step or a prefill step that does not end the prompt (`norm_capture_test.cpp`). The attention's capture: the last row's live scores within the kernel's accuracy of f64 dot products from the same queries and stored keys, the maximum exactly theirs, the sum within the fold's margin; the same bits for a query as a one-token step, split, and as an unsplit prefill step's last row; a window over a wrapped ring; a full-attention layer back to position 0; the slot's words past the live keys left alone; nothing in a decode step or a non-ending prefill step; the output the same bits whether the step captures or not (`attention_capture_test.cpp`). The weights launch: exp2(s − m) / l within (8 + 3|s − m|) × 2⁻²⁴ of the f64 quotient for the keys read, 0 past them, the stats and every other word untouched, nothing in other steps (`weights_test.cpp`). The ported kernel families (gather, norm, matmul, rope, attention, top-k) get no tests of their arithmetic: the oracle covers them end to end, by decision; the norm's and attention's capture outputs, new in slice 4 step 5, are tested here. | Built |
| Edit specs | An invalid edit (unknown kind or layer, neuron out of range, non-finite value, a Zero with a value, an empty range, two ranges of one neuron sharing a step, too many) is refused by name; an edit without its range is refused, never applied from step 0; ranges that only meet are allowed; Scale × 1 is an exact no-op; the table's layout, ranges placed at the run's origin, saturating to the end. `tests/contracts/edits/`. | Built |
| Cache | How much of the cache a run reuses: the longest common prefix of the tokens; the first position where the placed edits in force differ, an edit alone at its start, a change of kind or value bits where they first overlap, ranges split or ordered otherwise not at all. `tests/contracts/cache/`. | Built |
| Turn | The inspection: a limit of 0 runs the prefill, the last block scoring, discards its draw, plans no decode step, ends Limit with nothing emitted and the prompt kept; a limit of 1 still emits its draw. `tests/contracts/turn/`. | Built |
| Chat template | Gemma 3's template, from the model file, renders one user message as `<bos><start_of_turn>user\n{message, trimmed}<end_of_turn>\n<start_of_turn>model\n`; a conversation renders each turn, assistant as `model`; a system prompt joins the first user turn; turns that do not alternate are refused by name. `tests/contracts/template/`, TypeScript, against Charlotte's frozen Gemma references (`tests/fixtures/template/`) and the template in the committed tokenizer fixture. | Built |
| Delivery | SHA-256 matches published test vectors, whole and fed in pieces; the pinned file is kept only when it arrives whole, as many bytes as the pin says, with the pin's SHA-256, and a copy already kept is not downloaded again; a stated size that differs, a download that ends early or runs long, or a hash that differs is refused by name and nothing is kept; a download aborted partway keeps nothing and discards what it wrote. `tests/contracts/delivery/`, TypeScript; the store and the server are in-memory stand-ins at the module's own interfaces; the real fetch and OPFS are not tested. | Built |
| Shape | What the deck shows at a cell is the neuron folded there, a heat map of its size, whichever its sign: a slot folds 96 to a row in reading order, and each cell back to its neuron, a short last row ending in empty cells, and a box of cells to its neurons, clipped to the grid; each neuron's pixel is at its cell; v and −v are one colour; 0 is the ramp's first colour, the slot's scale (its 99th-percentile finite magnitude, or the largest when that is 0) its last, and a larger magnitude never further back along the ramp than a smaller one; infinities are full heat and NaN its own colour, and none sets the scale; what is not a grid, a neuron or the slot's width, or a ramp of fewer than two colours, is refused; heatOf is paint's colour, and an overlay colours its cells at the slot's own scale and nothing else. The strongest neurons rank by magnitude, either sign, ties in order, NaN never. Bytes read as whole megabytes, values with their sign and two places, a scale's end with two significant digits. The gamma and the deck's own palette and scene are not locked. `tests/contracts/shape/`, TypeScript, plain arrays. | Built |
| Branch | A reply as words, every token in one, a word beginning at a token whose text begins with white space or after one ending with a line break, a token completing no character going with its word, each word's branch point its end; a branch sends the reply's edits cut at its point and the pins from it, a pin held unchanged across the point one range, -0 apart from 0, never two edits of a neuron at one step; accepting keeps the base's tokens to k and the branch's, with the branch's edits; a point inside a word, left by an accepted branch, reads as the word's text up to it; a branch point outside the reply is refused. `tests/contracts/branch/`, TypeScript, plain arrays. | Built |
| Pins | The pins held for the next run: at most one edit a neuron, in the order first pinned; adding replaces in place and adding what is held changes nothing; removing takes only the named neurons of the named layer; chips group by layer and edit, -0 apart from 0, in the order each began; a set sends its value, a zero 0, a scale the f32 product. `tests/contracts/pins/`, TypeScript, plain arrays. | Built |
